# **App Name**: Fault Tracker

## Core Features:

- Form Input: Capture details including radiographer's name, system number, facility, detected fault, and detection date via a simple form.
- Data Sorting: Sort the form data to find particular Faults when you want
- Form Generation: Generate a new form that asks all the questions to fill the form

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2), reminiscent of clarity and precision.
- Background color: A very light blue (#E5F5F9), complementing the primary.
- Accent color: A muted green (#8FBC8F), for subtle highlights and calls to action.
- Body and headline font: 'Inter' (sans-serif) for a modern, objective look that suits both headlines and body text.
